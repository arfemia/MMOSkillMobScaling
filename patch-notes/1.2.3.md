Scaled mobs in the Headless Horseman's graveyard from Seasons of Orbis get a level band of their own, and with CommonLib 2.4.0, rare creatures no longer leave a trail of sparkles behind them.

MMO Mob Scaling 1.2.3 runs on Hytale Update 7 (0.7.x) with Ziggfreed's CommonLib 2.3.0 or newer and MMO Skill Tree 1.7.1 or newer, the same as 1.2.2, so you can update it on its own.

### New

- Added level bands for the Headless Horseman's graveyard from Seasons of Orbis: scaled mobs there sit between level 1 and 10, and between 15 and 25 on the hard ride. A strong group pushes them up only to the top of that band.

### Fixes

- Fixed rare, epic and legendary creatures leaving a trail of glowing drop sparkles behind them as they move. This fix comes with CommonLib 2.4.0.
- Fixed the mob inspector showing 0 health on a mob that was still alive.
- Fixed scaled mobs sometimes showing an empty health bar and standing frozen while they still had health. This fix comes with CommonLib 2.4.0.
- Fixed memory that built up on servers that open and close lots of dungeon or event worlds.
- Fixed the `/mobscaling` help showing a raw text key instead of a description for the preset name.

### For server owners

- To change a graveyard's band, save a file of the same name, `Hallows_Eve_Graveyard.json` or `Hallows_Eve_Graveyard_Hard.json`, in `mods/MmoMobScaling/worlds/`.
- Removed the example caster creature added in 1.1.0. It was only ever an example and nothing else used it. The Ember Dragon's example caster roster is unchanged.
