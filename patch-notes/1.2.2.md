Mob scaling for Hytale Update 7. Nothing about how mobs scale changes. Requires Ziggfreed's CommonLib 2.3.0 and MMO Skill Tree 1.7.1, which ship alongside it.

- **Runs on Update 7 (0.7.x) servers.** Rebuilt for the new server line, so a 0.7 server loads it without the outdated-mod warning.
- **Update all three together.** Ziggfreed's CommonLib and MMO Skill Tree each have an Update 7 build. With an older one installed, the server refuses to load mob scaling and names the mod to update, rather than running it beside a build that is quietly broken on Update 7.
- **Added a casters folder for server owners.** `mods/MmoMobScaling/casters/` takes your own caster rosters, one file per roster, the way the difficulty folder takes zone floors. To give the Ember Dragon its example spells back, save `demo_boss_caster.json` there holding `{"Enabled": true}`; you no longer need a content pack for it. The `README.txt` in the folder explains the rest.
- **The start-up log counts caster rosters that are on and off separately**, so the example roster, which ships off, no longer looks like it is running.
- **The mob inspector says what each affix does.** When you look at a mob with affixes, the inspector card now shows each affix's description on a line under its name, such as "Heals a little with every hit it lands." for Vampiric.
